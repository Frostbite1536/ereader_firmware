# SD card layout

Copy the contents of this folder to the root of the device's microSD card
(the firmware also creates the folders on first boot):

- `/docs` — Writer output (`draft-001.txt`, ...)
- `/decks` — flashcard decks, one `question|answer` per line
- `/firmware` — firmware images for the swap flow (e.g. CrossPoint's
  `firmware.bin` from its GitHub releases)
